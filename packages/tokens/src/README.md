# BidayaX Tokens

The tokens package is the only approved home for raw visual values in Phase 2.

Token groups answer the validation questions:

- Colors exist to lock the dark luxury material system and prevent one-off palettes.
- Typography exists to separate display, heading, body, and data roles before screens are built.
- Spacing exists to keep layout rhythm consistent across cards, dashboards, and receptionist surfaces.
- Radius exists to preserve a restrained executive interface language.
- Elevation exists to define surface hierarchy without random shadows.
- Motion exists to keep animation deliberate, accessible, and optional.
- Z-index exists to prevent overlay conflicts.
- Breakpoints exist to keep the foundation mobile-first and responsive.

No UI code should use raw hex values directly. Components consume semantic classes, CSS variables, and token-backed Tailwind configuration.
