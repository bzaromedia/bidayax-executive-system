# BidayaX Visual Language

The Phase 2 visual language is executive, luxurious, intelligent, minimal, premium, trustworthy, high-contrast, enterprise-grade, brushed-metal inspired, dark luxury first, mobile-first, and accessible.

## Material Direction

The material system should feel like BidayaX luxury visual language fused onto a brushed metal executive business card.

Supported material ideas:

- Deep black.
- Charcoal.
- Gunmetal.
- Brushed titanium.
- Soft gold.
- Champagne gold.
- Muted bronze.
- Pearl white.
- Executive blue-black.
- Controlled highlight accents.

## Avoid

- Generic SaaS styling.
- Crypto or neon overload.
- AI-generated visual clutter.
- Excessive glassmorphism.
- Random gradients.
- Unapproved icons.
- Hardcoded values.
- One-off styling.
