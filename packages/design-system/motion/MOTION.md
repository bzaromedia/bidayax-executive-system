# Motion Governance

GSAP and Motion are documented as future options, not Phase 2 animation requirements.

## Phase 2 Rules

- Use tokenized durations and easing.
- Prefer no animation unless it clarifies state or hierarchy.
- Respect reduced-motion preferences.
- Do not add decorative motion to foundational components.
- Do not add app-specific motion patterns before screens are approved.

## Future Motion Uses

- State transitions.
- Focus and disclosure feedback.
- Priority changes in dashboards.
- Receptionist workflow state changes.
- QR conversion feedback where measurable.
