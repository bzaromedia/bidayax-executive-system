# Accessibility Foundation

Accessibility is a release gate, not polish.

## Phase 2 Commitments

- Components expose semantic HTML first.
- Focus states are token-backed and visible.
- Inputs support labels and accessible names.
- Icon-only buttons require `aria-label`.
- Motion remains optional and must respect reduced-motion preferences.
- Storybook includes an accessibility review addon.

## Future Checks

- Contrast validation for all token pairs.
- Keyboard navigation for all interactive patterns.
- Screen reader naming for controls.
- Reduced-motion handling for future motion work.
- Form error messaging before production forms exist.
