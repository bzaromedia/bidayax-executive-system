# BidayaX Receptionist Agent

Phase 8 creates the Polyglot Receptionist OS foundation as a deterministic simulation service.

## Commands

```bash
pnpm --filter @bidayax/receptionist-agent test
pnpm --filter @bidayax/receptionist-agent build
```

## Scope

This package models simulated receptionist interactions, language profiles, intent classification, task generation, escalation recommendations, and workflow events.

It does not connect live phone calls, OpenAI Realtime, Twilio, Gmail, Microsoft 365, calendar systems, or external workflow engines.
