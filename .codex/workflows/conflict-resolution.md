# Conflict Resolution

When agents disagree:

1. compare each claim against repository evidence;
2. inspect the relevant code or document directly;
3. run targeted validation where possible;
4. apply the source-of-truth hierarchy from root `AGENTS.md`;
5. ask the Advisor to adjudicate unresolved technical conflicts;
6. record the decision in `docs/codex/DECISION-LOG.md`;
7. escalate to the user only when the choice is product, legal, business, deployment, or otherwise irreversible.

Do not resolve conflicts by majority vote.
