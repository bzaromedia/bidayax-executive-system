# Completion Definition

Work is complete only when:

1. the requested behavior or artifact exists;
2. acceptance criteria are tied to evidence;
3. required validation is complete and accurately reported;
4. critical and major findings are resolved;
5. Advisor Gate C allows acceptance when required;
6. documentation reflects reality;
7. no placeholder behavior, fabricated output, hidden failure, or misleading claim remains;
8. unrelated repository behavior is not knowingly degraded;
9. residual risks are explicitly listed;
10. the final Git state is reported accurately.
