# Executive Card Download Packages

The Executive Card v1.0 supports isolated internal download packages for the three production executive cards.

## Packages

Each package is generated from `packages/config/executives/profiles.ts` and contains only one executive profile:

- `downloads/executive-cards/ad-garner/`
- `downloads/executive-cards/naimah-barnes/`
- `downloads/executive-cards/sean-hall/`

Each package contains:

- `profile.json`
- the executive `.vcf` file
- `qr.png`
- `assets/avatar-placeholder.png`
- `assets/logo.png`
- `assets/mark.png`
- `README.md`

Zip exports are generated beside the package folders:

- `downloads/executive-cards/ad-garner-executive-card.zip`
- `downloads/executive-cards/naimah-barnes-executive-card.zip`
- `downloads/executive-cards/sean-hall-executive-card.zip`

## Generate Packages

```powershell
pnpm cards:downloads
pnpm cards:downloads:verify
```

The generator reads the production profile source and writes the package folders and zip files. Do not edit generated profile data manually.

## Download Routes

Internal package download routes:

- `https://theexecutivecard.online/card/ad-garner/download`
- `https://theexecutivecard.online/card/naimah-barnes/download`
- `https://theexecutivecard.online/card/sean-hall/download`

Each route validates the slug and returns only that executive zip file. If the zip file is unavailable, the route returns a safe `503` response that instructs the operator to run `pnpm cards:downloads`.

## Avatar Replacement

Replace the file inside the executive package:

```text
downloads/executive-cards/{slug}/assets/avatar-placeholder.png
```

Keep the same file name for package compatibility. Avatar replacement does not require code changes.

## Update Profile Data

1. Edit `packages/config/executives/profiles.ts`.
2. Run `pnpm cards:downloads`.
3. Run `pnpm cards:downloads:verify`.
4. Run the normal release verification commands before deployment.

## Regenerate QR and vCard

QR and vCard files are regenerated by `pnpm cards:downloads`. The vCard is built with the same production helper used by the card route.

## Conflict Avoidance

- Do not create shared profile files inside `downloads/executive-cards/`.
- Do not copy another executive profile into a package.
- Do not rename another executive's package folder.
- Do not reuse a zip file across executives.

## Production Safety Notes

- Packages must not contain secrets, API keys, passwords, database URLs, or environment files.
- Packages are for internal operational distribution.
- The download route is slug-scoped and returns only the matching executive package.
- Run `pnpm cards:downloads:verify` after every package regeneration.
