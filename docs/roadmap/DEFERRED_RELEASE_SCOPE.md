# Deferred Release Scope

This internal roadmap note preserves ideas removed from the active v1.0 product surface during the Production Truth Purge Gate.

The Executive Card v1.0 includes only implemented, tested, production-buildable capabilities. Deferred enterprise trust layers are not active product capabilities in v1.0.

Deferred directories removed from the active release tree:

- `apps/receptionist-console`: future receptionist console app.
- `services/api`: future standalone API service.
- `services/event-ledger`: future standalone event ledger service.
- `services/notification-worker`: future notification worker.
- `packages/sdk`: future internal SDK.

Deferred enterprise layers:

- Specialist Agent Collective.
- Full Data Trust Fabric.
- Verification Layer.
- IP Trust Fabric.
- Bank Trust Layer.
- Continuous Reverification.
- Enterprise Platform.
- Operational Excellence.
- Technical Data Room.
- Certification Readiness.

These items require implementation, tests, build integration, documentation, and release verification before they can return to the active product surface.
