# Production Activation Gate

This gate governs Phase 11I Communications production activation only. It does
not authorize broader platform production activation or any later phase.

## Not Authorized In Phase 11A

The following remain prohibited:

- SSH, VPS, or hosting-control-panel access
- production-data access
- provider-console or provider-API access
- credential retrieval or provisioning
- provider enablement
- provider selection finalization
- credential provisioning
- phone-number purchase
- live inbound calls
- live outbound calls
- live voice execution
- live messaging execution
- deployment

## Required Before 11I Approval

- merged activation record with approver, environment, provider, exact actions,
  scope, expiry, rollback evidence, and validation evidence
- approval from the BidayaX LLC owner or an explicitly named production delegate
- provider decision matrix completed
- legal review completed
- durable replay protection implemented
- consent and suppression enforcement verified
- fraud controls verified
- tenant and platform kill switches verified
- sandbox evidence completed
- staging validation completed
