# Polyglot Receptionist Settings

The Polyglot Receptionist settings system controls the workflow foundation for routed executive requests.

## Active in v1.0

- Enabled/disabled setting per executive card.
- Voice style and mood selection for workflow tone.
- Standard or custom greeting mode.
- Supported language list and default language.
- Request type configuration.
- Handoff email configuration.
- Consent-required setting.
- Settings validation and audit event creation.

## Default Greeting

Welcome. I can help route your request, schedule a meeting, or connect you with the right executive contact.

## Production Boundary

The receptionist remains a human-approved workflow foundation in v1.0. Production voice and outbound calling remain disabled unless provider flags and operational controls are configured separately.
