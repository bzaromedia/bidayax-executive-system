# Metrics Catalog

## Metric Examples

- `api_latency_ms`
- `card_view_count`
- `vcard_download_count`
- `intent_score_count`
- `graph_build_duration_ms`
- `receptionist_task_count`
- `telephony_readiness_failures`
- `safety_gate_blocks`
- `database_query_duration_ms`
- `dashboard_query_duration_ms`

## Rules

- Metrics must come from real system behavior.
- Do not invent uptime, growth, or success rates.
- Use dimensions sparingly.
- Sanitize dimensions before storage.
