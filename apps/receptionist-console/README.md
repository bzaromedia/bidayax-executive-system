# Receptionist Console

`apps/receptionist-console` is the future dedicated operator console for The Executive Card Polyglot Receptionist OS. In v1.0 it provides typed console data-shape utilities only; the production dashboard remains the active UI for receptionist workflow visibility.

The console model is intentionally separated from live provider dispatch. Phone, realtime voice, calendar, and outbound notifications require configured providers and human-approval policy before production dispatch.
